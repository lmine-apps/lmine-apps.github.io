STEP 1

🚀 初回セットアップ

iPhoneでSafariから開いて通知許可→ホーム画面に追加。以降はホーム画面アイコンから即起動できます。

  1. iPhone Safari で apps.l-mine.com/kayomama-admin/ を開く
    （初回のみ、とーるさんから受け取った専用URL）
  2. 画面下の「共有」ボタン（□に↑）→「ホーム画面に追加」
  3. ホーム画面のアイコン🌸をタップして起動
  4. 「通知を送信します」ダイアログ → 許可 をタップ
  5. 設定タブの「通知トークン」が登録済 ✅になれば準備完了

▲ iPhoneロック画面での通知

2種類の見え方

  1. バックグラウンド時：アプリを閉じてても、iPhoneのロック画面に通知が届く。タップで管理アプリが起動
  2. アプリを開いている時：画面下部にトースト表示＋自動リロード
💡 通知が届かない時
iPhoneの「設定」→「通知」→「Safari（またはブラウザ）」で通知が許可になっているか確認。もしくは管理アプリを一度開いて設定タブから「テスト通知」で確認できます。
STEP 7

🌸 日々の使い方（1日の流れ）

推奨ルーティン。無理せず1日1〜2回のチェックで大丈夫です。

  1. 朝（またはお昼）：アプリを開いて「💬 関心」タブ→未対応があればLINEで対応→ステータス更新
  2. 通知が届いたら：その場でLINE対応 → 管理アプリでステータス「LINE連絡済」に
  3. 週1回程度：ホーム画面で全体の進捗ファネルをチェック。Day3で止まってる方などに声かけ
  4. 月末：「関心」タブでその月の成約数を確認。手応え把握
STEP 8

❓ 困ったとき

よくあるトラブルと対処法。

通知が届かない

  1. iPhoneの設定 → 通知 → Safariで通知が有効か確認
  2. 管理アプリの設定タブで「🔔 テスト通知」→ 届けばOK、届かなければ次へ
  3. 設定タブで「ログアウト」→ 再度URLを開いて通知を許可し直す

画面が真っ白 or 更新されない

  1. ページを下から上へスワイプ（プルダウン更新）
  2. 右上の「↻ 更新」ボタンをタップ
  3. それでもダメならホーム画面のアイコンを長押し→アプリを削除→再度Safariから追加

「invalid admin token」エラーが出た

とーるさんに連絡してください。管理トークンの再発行が必要な状態です（機種変更時などにも発生することがあります）。
